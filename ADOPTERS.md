# Adopters

Organizations and projects that use Smelt. This file is one of the two opt-in
adoption signals (the other is the pre-filled `[quickstart]` issue the
quickstart can print): if you trained or shipped something with Smelt, add an
entry by pull request. Counts taken from this file or from those issues are
lower bounds; Smelt sends no telemetry.

Entry format:

```markdown
- **Organization or project** — what you use it for. Package and task, plus a
  link. (Date)
```

Example:

```markdown
- **Example Analytics Co** — consent-banner detection in the onboarding flow.
  `@smelt-oss/consent-banners`, consent banners. https://example.com (2026-09-08)
```
