# Decision records

Decisions live here as MADR-format markdown: `NNNN-title.md` with status,
date, context, decision, and consequences.

Rules:

1. Records are immutable once accepted. Corrections arrive as new records.
2. Frozen files (`prepare.py`, `train.py`, `eval.py`, the rules grammar)
   require a decision record and a seven-day comment window before change.
3. Numbering is sequential. Record 0001 is the original kill-criteria clock;
   0002 is the naming decision. Record 0003 defines the Steel pilot and
   supersedes the dates and continuation rules in 0001. Record 0004 confirms
   consent-banner root detection as the first Steel detector task. Record 0005
   prepares the 2026-10-16 pilot evidence review. Record 0006 is the archive
   and transfer procedure that runs for every stopping outcome.
